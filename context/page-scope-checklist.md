“组织关系”指学联与 UNSW、Arc 等机构经核实的正式联系，不是内部上下级关系；注册或合作事实不能表述为未经证实的官方代表身份或背书。

编辑方式已确认为 `/admin` → 登录验证 → 内容保存接口 → GitHub 内容文件 → 自动构建发布，详见 `admin-publishing-architecture.md`。六个公开页面范围不变。

## 所有页面共用的规则

- 每年的管理层负责官网内容及 Eventbrite 活动，技术部负责页面布局、样式、部署、同步及故障处理。
- 内容后台只开放已定义的文字、图片、链接、列表顺序、公开状态及适用的预设颜色；不允许编辑布局、字体、CSS、HTML 或动画。
- 正式 Logo 和品牌素材按品牌规范使用，不允许自由改色、裁切或替换为非正式素材。
- 页脚统一展示中英文名称、官方邮箱、Instagram、小红书、微信公众号、抖音、Eventbrite 和版权信息；邮箱与社交入口统一在网站设置维护。
- 普通活动时间统一使用 `Australia/Sydney`，状态包括即将举行、进行中、已结束、已取消。
- Eventbrite 读取或同步失败时，活动列表和详情显示“活动信息暂时无法加载，请稍后重试”，不能显示“暂无活动”。自动重试或定时同步继续运行，成功后自动恢复展示，无需手动部署。
- 活动故障不影响首页、团队、品牌活动等官网内容页面的展示与发布；不强制保留旧活动快照。成功但没有匹配活动时才显示空数据状态。
- 官网不提供公众注册登录、个人中心、优惠券、美食地图、AI 助手和旧管理后台；`/admin` 仅供受邀管理层登录编辑，不进入六项一级导航。
- 不开发自动换届撤权；可保留离任协助者权限，并保留人工撤销方式。
- 编辑、保存草稿、预览和发布是不同操作：草稿私有保存，预览需要登录，新上传未发布图片默认受保护，发布时才开放确认版本。
- 技术部编辑前沟通并错开时间；系统只保留简单版本检查，不开发复杂协同编辑。

## 确认边界

六个页面的展示内容和编辑边界已确认，后续增删范围需依据用户新要求更新。品牌活动采用统一颜色还是预设主题色仍待选择，不默认增加自由配色能力。身份服务、GitHub 草稿策略、图片存储、部署平台、具体字段实现及活动同步恢复间隔在 PoC 中确定；正式文案和照片待布局调整后补充。
