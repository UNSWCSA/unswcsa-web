# 新南学联网站改造上下文入口

本目录是新版网站简化改造的主要背景资料。没有此前对话记录时，应先阅读本文件，再按以下顺序阅读：

1. `website-simplification-context.md`：确定产品范围、页面结构、数据来源和明确不做的功能。
2. `brand-guidelines.md`：确定品牌名称、颜色、字体方向和正式资产的使用规则。
3. `implementation-plan.md`：确定实施顺序、验证要求和旧系统退役条件。
4. `project-status.md`：确认当前进度、已经确定的事项和仍待决定的事项。

## 文档优先级

- 新版简化改造以本目录中的文件和用户最新明确要求为准。
- 仓库原有 README、PRD、代码和配置用于理解现状，不代表新版仍需保留原有功能。
- 如本目录内部出现冲突，以用户最新明确要求为准；不能确认时先提出问题，不自行扩大需求。
- 品牌手册和 `frontend/public/brand/` 中的正式资产优先于文字推断。

## 执行约束

- 按 `implementation-plan.md` 分阶段实施，不跳过 CMS 和 Eventbrite PoC。
- CMS 与 Eventbrite 保持独立，不重新建立承载全部业务的通用后端。
- 在新版完成验证、数据完成迁移且得到明确确认前，不物理删除旧系统或旧数据。
- 不为了补全页面自行编造学联资料、团队成员、奖项、活动数据、联系方式或社交账号。
- 每完成一个阶段或确认一项关键选型，应同步更新 `project-status.md`。
