# 新南学联网站改造状态

最后更新：2026-09-14

## 当前阶段

- 网站简化目标、页面范围、数据源边界、品牌基础规范和实施顺序已经形成文档。
- 正式品牌资产已整理到 `frontend/public/brand/`。
- 代码仓库仍保留原有完整系统；尚未记录架构审计、CMS PoC、Eventbrite PoC 或新版上线已经完成。
- 下一步应从 `implementation-plan.md` 第一阶段“架构审计与归档”开始，并按顺序推进。

## 已确定事项

- 前端继续使用 React、TypeScript 和 Vite。
- 主导航保留：首页、关于我们、部门与团队、品牌活动、全部活动、加入我们。
- CMS 管理长期官网内容；Eventbrite 管理普通活动；两个数据源互不依赖。
- 不重新建设统一的重型 CSA Backend。
- 团队按自然年归档；品牌活动只展示已结束的代表性活动。
- 普通活动只提供年份和月份选择，活动状态直接显示在卡片中。
- Instagram、小红书、微信公众号、抖音和 Eventbrite 均属于官方入口。

## 实施前或 PoC 后待确定

- CMS 产品、内容模型实现方式和管理员权限配置。
- 网站部署平台，以及 Eventbrite 同步和缓存的具体实现平台。
- Eventbrite 官方账号、API 权限、同步限制和真实数据结构。
- 正式域名、页面路径和重定向安排。
- 网站正式文案、历届团队、荣誉、品牌活动资料、照片、联系方式、社交链接和招新入口。
- 品牌字体的网页授权及字体文件；Logo 联合展示、安全留白和最小尺寸等尚未提供的正式规则。
- 旧用户及报名数据的保留、导出和删除要求。

以上待定事项应在对应实施阶段确认；在此之前使用适配层、占位数据或明确的待办项，避免把临时选择固化为架构。
