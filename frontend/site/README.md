## Eventbrite 真实活动接入（2026-10-05）

全部活动现通过同源 `/api/events` 读取公开 Worker，浏览器不持有 Eventbrite 凭据。开发及本地构建预览使用 Vite 代理；生产构建自动生成 Cloudflare Pages `_worker.js` 和 `_routes.json`，只为此接口转发到 `https://csa-events.unswcsa-exec.workers.dev/api/events`，其他页面由静态资源服务处理。无需修改现有活动 Worker 或内容后台。

Cloudflare Pages 上传完整 `dist-site-preview`（包括这两个文件）；普通静态托管不能运行该代理，需另配同源接口。部署后的运行时链路尚未云端验证。本次未部署。
